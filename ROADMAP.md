# 🗺️ DSA Mastery Roadmap

A structured, 4-phase curriculum guiding progression from core computational primitives to advanced competitive problem-solving.

---

## 🧭 Mastery Architecture

```text
[ Phase 1: Foundations & Linear DS ] 
  └── Contiguous memory, two pointers, sliding window, prefix sums, linked lists, stacks & queues

[ Phase 2: Non-Linear Structures & Search Spaces ] 
  └── Binary search invariants, trees & BST, heaps/priority queues, BFS/DFS graph traversals

[ Phase 3: Advanced Optimization, DP & Graph Theory ] 
  └── Dynamic programming, backtracking & pruning, topological sort, DSU, shortest paths, Trie

[ Phase 4: Hard Synthesis & Competitive Fluency ] 
  └── Monotonic structures, complex state machines, bitmask DP, 90-min contest simulations
```

---

## 📌 Phase 1: Foundations & Linear Data Structures

*Objective: Establish rock-solid fluency with contiguous memory, pointer manipulation, and linear scan patterns.*

- [ ] **Arrays & Strings**
  - [ ] In-place manipulations & array rotations
  - [ ] Frequency vectors, anagrams, and rolling hash foundations
  - [ ] 2D matrix spiral and diagonal traversals
- [ ] **Two Pointers & Sliding Window**
  - [ ] Opposite-direction pointers (palindromes, sorted pair sums)
  - [ ] Same-direction fast/slow pointers (cycle detection, partition)
  - [ ] Fixed-size sliding windows (substring counts)
  - [ ] Variable-size sliding windows (longest/shortest valid subarray)
- [ ] **Prefix Sums & Hashing**
  - [ ] 1D & 2D range sum prefix matrices
  - [ ] Subarray sum equals $K$ using hash maps
- [ ] **Linked Lists**
  - [ ] Single and doubly linked list manipulation
  - [ ] In-place linked list reversal (full & $K$-group)
  - [ ] Fast & slow pointer techniques (Floyd's Cycle Finding)
- [ ] **Stacks & Queues**
  - [ ] Balanced parenthesis and expression evaluation
  - [ ] Monotonic stack basics (Next Greater Element)
  - [ ] Min-Stack / Max-Stack constant time design

---

## 📌 Phase 2: Non-Linear Structures & Fundamental Search

*Objective: Master hierarchical structures, logarithmic search spaces, and graph traversals.*

- [ ] **Binary Search**
  - [ ] Classic boundary search on sorted arrays
  - [ ] Search in rotated sorted arrays
  - [ ] Binary search on monotonic solution spaces (`min/max` predicate)
- [ ] **Trees & Binary Search Trees (BST)**
  - [ ] Recursive and iterative tree traversals (Pre, In, Post, Level-order)
  - [ ] Lowest Common Ancestor (LCA) in Binary Trees & BSTs
  - [ ] Tree diameter, path sums, and depth calculations
  - [ ] BST validation, insertion, deletion, and balancing concepts
- [ ] **Heaps & Priority Queues**
  - [ ] Top-$K$ elements & $K$-th largest element selection
  - [ ] Two-heap pattern (streaming median finding)
  - [ ] $K$-way merge of sorted lists
- [ ] **Graph Traversal Foundations**
  - [ ] Adjacency list vs adjacency matrix representations
  - [ ] Breadth-First Search (shortest path in unweighted graphs)
  - [ ] Depth-First Search (connected components, cycle detection)
  - [ ] Grid-based search (Flood Fill, Number of Islands)

---

## 📌 Phase 3: Advanced Optimization, DP & Specialized Structures

*Objective: Formulate state transitions, combinatorial search trees, and complex graph algorithms.*

- [ ] **Backtracking & Recursion**
  - [ ] Power sets, permutations, and combination sums
  - [ ] Constraint satisfaction (N-Queens, Sudoku Solver)
  - [ ] State space tree pruning & branch-and-bound
- [ ] **Dynamic Programming (DP)**
  - [ ] 1D memoization & tabulation (Climbing Stairs, House Robber, Coin Change)
  - [ ] 2D Grid DP (Unique Paths, Minimum Path Sum)
  - [ ] Classic 0/1 & Unbounded Knapsack variations
  - [ ] Longest Common Subsequence (LCS) & Longest Increasing Subsequence (LIS)
  - [ ] State compression & space reduction techniques
- [ ] **Advanced Graph Theory**
  - [ ] Topological Sorting (Kahn’s algorithm & DFS post-order)
  - [ ] Disjoint Set Union (Union-Find with path compression & union by rank)
  - [ ] Shortest path algorithms (Dijkstra, Bellman-Ford)
  - [ ] Minimum Spanning Tree (Kruskal’s & Prim’s algorithms)
- [ ] **Trie (Prefix Tree)**
  - [ ] Prefix matching, dictionary autocompletion, word search
  - [ ] Bitwise Trie for maximum XOR queries

---

## 📌 Phase 4: Hard Synthesis & Competitive Fluency

*Objective: Master high-complexity combinations, monotonic optimization, and timed problem-solving.*

- [ ] **Advanced Monotonic Structures & Intervals**
  - [ ] Monotonic Queue (Sliding Window Maximum)
  - [ ] Complex interval scheduling, sweeping line algorithms
- [ ] **Multi-Pattern DP & State Machines**
  - [ ] Multi-dimensional DP with state machine transitions (Stock trading variants)
  - [ ] Bitmask Dynamic Programming
  - [ ] Digit DP foundations
- [ ] **Interview & Contest Strategy**
  - [ ] Time-boxing: Solve 3/4 problems reliably in a 90-minute window
  - [ ] Systematic edge-case validation checklist prior to code execution
  - [ ] Routine post-solve complexity optimization and refactoring
